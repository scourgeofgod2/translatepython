# Test PDFs for mirapdf

Download a complex academic PDF and save it here as `sample.pdf`, or pass any path to `smoke_translate.ps1`.

Good free samples (multi-column, formulas, tables):

- Attention Is All You Need: https://arxiv.org/pdf/1706.03762
- Any arXiv paper PDF works well.

Do not commit large PDFs (samples/*.pdf is gitignored).
